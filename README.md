# Mediumoptimierung für Gordonia desulfuricans

Bachelorarbeit, [Hochschule], [Zeitraum]

## Ziel
Maximierung des Wachstums von Gordonia desulfuricans durch Mediumoptimierung.

## Messung
Wachstum per Plate Reader (LT4500), 96-Well, Flachboden.

## Struktur
- data/raw: unveränderte Geräteexporte (nicht editieren)
- data/metadata: Plattenlayouts, Medienzusammensetzungen
- data/processed: berechnete Kennzahlen
- scripts: Auswertungsskripte (R)
- designs: Versuchspläne je Serie
- results: Abbildungen und Tabellen
- docs: Entscheidungen, Protokolle
